# Social Fetch

Hosted social-media scraper API returning structured JSON for public profiles, posts, comments, engagement metrics, transcripts, and search across ~23 platforms. Offers a REST API with public OpenAPI contract, a hosted MCP server, an llms.txt file set, published agent skills, and x402 pay-per-call payments.
